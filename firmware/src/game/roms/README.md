# CHIP-8 carts

`snek.ch8`, `superpong.ch8`, and `br8kout.ch8` are from
[JohnEarnest/chip8Archive](https://github.com/JohnEarnest/chip8Archive)
and are dedicated to the public domain under **CC0**.

| File | Title | Author | Keys |
| --- | --- | --- | --- |
| `snek.ch8` | Snek | John Earnest | 5/7/8/9 (up/left/down/right) |
| `superpong.ch8` | Super Pong | offstatic | 5/8 and 7/9, 6 to start |
| `br8kout.ch8` | Br8kout | SharpenedSpoon | 7 left, 9 right |

They are compiled into the M7 image as Game library titles. Copy the `.ch8`
files onto eMMC `/user/game` only if you want them in Files as well.
